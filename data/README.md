# Data folder

Place the real dataset here as `data/student-mat.csv`.

1. Open https://archive.ics.uci.edu/dataset/320/student+performance
2. Click **Download** and unzip the archive.
3. Copy `student-mat.csv` (Mathematics, 395 rows, semicolon-separated) into this folder.

The dataset is published by UCI under a CC BY 4.0 licence (check the dataset page for current terms). To keep the repository light and avoid redistribution questions, the file is **not** included here.

Citation: P. Cortez and A. Silva, "Using Data Mining to Predict Secondary School Student Performance", 2008. UCI Machine Learning Repository.

For a quick smoke test only, `sample_data/synthetic_student_mat.csv` is a **synthetic (random, not real)** file with the same columns.
